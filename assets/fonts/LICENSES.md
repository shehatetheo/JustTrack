# Fonts

All four families are licensed under the SIL Open Font License 1.1 and are bundled here as Latin subsets.

- **Inter** by Rasmus Andersson: body text, controls and numbers.
- **Cinzel** by Natanael Gama: display capitals.
- **Cormorant Garamond** by Christian Thalmann: italic taglines.
- **UnifrakturMaguntia** by j. 'mach' wust: blackletter accents.

The name "JustTrack" is set in the system's Helvetica and needs no font file.
